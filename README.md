# Ticket Manager

Landing page for Ticket Manager, a Windows app for tracking event tickets.

## Edit
Open `index.html`. Replace the `href="#"` on the Download for Windows button (near the bottom) with your real download link, for example a GitHub Releases URL to your installer. Update the feature text to match what your app actually does.

## Publish with GitHub Pages
1. Upload `index.html`, `screenshot.png` and `README.md` to the repository root.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. The site will be live at `https://karcha3.github.io/Ticket-Manager/`.
